## File formatting

Files should be csv formatted like this:

English, Language1, Language2

source text, L1 text, L2 text

Visually, it would look like this:

| English | Language1 | Language2 |
| --- | --- | --- |
| source text | L1 text | L2 text |

## Placeholders
Placeholders are surrounded by { }. They can be empty or have suggested text.
