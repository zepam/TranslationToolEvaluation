# Notebooks

This directory contains Jupyter notebooks used to explore, evaluate, and compare translation tools for this repository.

## Contents

- [convert-fcc.ipynb](convert-fcc.ipynb): converts the FCC PDF source material into a sentence-delimited CSV file.
- [similarity-analysis.ipynb](similarity-analysis.ipynb): finds near-duplicate sentence groups and compares translations for similarity-based analysis.
- [translation-analysis.ipynb](translation-analysis.ipynb): loads translated JSONL data, computes embeddings and cosine similarity, clusters translations, and produces CSV/plot outputs.

These notebooks are exploratory analysis and conversion workflows rather than a single linear pipeline. Run only the notebook that matches the task you want to perform.
