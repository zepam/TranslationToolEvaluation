# Exhibit A — Dataset Description

- **Dataset name:** WARN Corpus: A Multilingual Parallel Corpus of Emergency Warnings and Translations
- **Version/date:** [version/date]
- **Description:** The WARN Corpus is a curated multilingual parallel corpus of agency-sourced emergency alerts and translations, together with related documentation and summary materials. The Dataset is intended to support academic research and, where authorized, operational reuse in multilingual emergency communication. The Dataset includes pre-translated alert templates, validated translations, anonymized per-language summary statistics, and, when available, baseline evaluation checks and related supporting materials. The Dataset is intended to facilitate systematic testing, comparative evaluation, and improvement of translation workflows, translation systems, and related tools for safety-critical communication. A manuscript describing the Dataset is in preparation.
